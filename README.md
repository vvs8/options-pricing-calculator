# Options Pricing Calculator

## Live Demo
https://options-pricing-calculator-vvs8.vercel.app/

This online options pricing calculator provides 3 tools for options pricing and analysis:

- **Option Profit Calculator** — Visualizes potential profit and loss outcomes for an options strategy. It uses the Black-Scholes model to calculate option prices and allows users to explore profit and loss across different underlying asset prices and points in time.

- **Option Price & Greeks Calculator** — Calculates call and put option prices and Greeks. An interactive interface allows users to examine how changes in model inputs affect option values and sensitivities.

- **Implied Volatility Calculator** — Iteratively back-solves the Black-Scholes model to derive implied volatility from the market price of an option contract.
